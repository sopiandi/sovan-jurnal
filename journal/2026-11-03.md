# November 3, 2026 - What a QR Code Really Is

A QR code looks high-tech, but it is really just text frozen into a
pattern of squares. The text can be a link, a payment number, or an ID.
Any phone camera can thaw the pattern back into text in a second.

What the picture cannot do by itself:

- It cannot expire.
- It cannot be used up.
- It cannot check who is holding it.

When a QR code works only once, that rule lives in the system behind the
code, not in the picture. The system remembers that this code has been
seen before and refuses it the second time. Understanding that split,
picture versus system, makes a lot of modern tools easier to judge:
the clever part is almost never the sticker. It is the bookkeeping
behind it.

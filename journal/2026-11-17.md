# November 17, 2026 - What Two-Factor Authentication Really Does

A password is a single key. If someone copies it, the door opens.
Two-factor authentication adds a second lock that uses a different
key — usually a code sent to your phone or made by an app. A thief
would need both keys at the same time, and the second one changes
every minute.

People often skip it because it feels like extra work. In practice
it costs a few seconds at login and saves weeks of trouble later.
Most account break-ins do not start with clever hacking. They start
with a password that leaked from some other website and was tried
everywhere.

The habit is simple to build:

- Turn it on for email first. Email is the key to almost every
  other account, because password resets go there.
- Use an authenticator app when it is offered. It works even
  without a mobile signal.
- Keep the backup codes somewhere safe, away from the phone.

A password alone is a hope. A password plus a second factor is
a plan. The few seconds it takes are the cheapest insurance an
account can have.

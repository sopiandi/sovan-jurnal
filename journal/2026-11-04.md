# November 4, 2026 - Backups in Plain Words

A backup is only one thing: a second copy kept somewhere else. If the
first copy is lost, damaged, or locked, the second copy keeps the work
alive.

Practical versions for a small shop:

- A photo of a notebook page is a backup.
- A file saved on a phone and also in cloud storage is a backup.
- A printed price list in a drawer is a backup.

The famous rule of thumb is 3-2-1: three copies, on two different kinds
of storage, with one copy outside the building. Most people do not need
the full rule. They need the habit behind it, which is asking one
question for anything important: if this disappeared tonight, where is
my other copy? If there is no answer, there is no backup yet.

# November 6, 2026 - Two-Step Verification, Explained Simply

A password is something you know. A verification code sent to your phone
is something you have. Two-step verification asks for both, so a stolen
password alone is not enough to break in.

The weak point is the phone number itself. Numbers get changed, SIM
cards die, and old numbers are forgotten. When the only way to receive
the code is a number that no longer works, even the real owner can be
locked out of an account with the correct password in hand.

Habits that prevent that trap:

- Keep the recovery number updated whenever you change numbers.
- Save backup codes somewhere safe when a service offers them.
- Stay signed in on one trusted device when you can.

Security settings feel boring on the day you set them. They are priceless
on the day something goes wrong.
